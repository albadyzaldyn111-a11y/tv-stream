# بنية TV Stream

## الرؤية

يتكون المشروع من تطبيق Flutter للمشاهدة، وواجهة REST مبنية بـFastAPI، وقاعدة PostgreSQL، وواجهة إدارة صغيرة. تحافظ البنية على فصل واضح بين بيانات القنوات، والتحقق من الحقوق، وحل مصادر البث، وواجهة المستخدم.

```text
Flutter UI
   |
   v
Channel Controller  --->  Favorites (local first; user sync later)
   |
   v
REST API /api/channels
   |
   v
Channel Repository ---> PostgreSQL
   |
   +--> Rights Filter: verified / official_source only
   |
   +--> Streaming Service ---> HLS Player only for verified HLS
   |
   +--> Official Source Launcher for official_source
```

## حدود الحقوق

لا يرسل الـAPI رابط `stream_url` إلى تفاصيل القناة إلا إذا كانت حالة الحقوق `verified` وكان المصدر HLS. القنوات ذات الحالة `official_source` تظهر كبطاقات قابلة للفتح على الصفحة الرسمية، بينما القنوات ذات الحالة `permission_required` تبقى في لوحة الإدارة ولا تظهر في القائمة العامة. هذا القرار يمنع أن يتحول وجود بث رسمي على موقع القناة إلى افتراض غير صحيح بامتلاك حق إعادة التوزيع.

## Backend

تُقسم خدمة FastAPI إلى إعدادات مركزية، جلسة قاعدة البيانات، نماذج SQLAlchemy، مخططات Pydantic، مستودع قنوات، خدمة فحص صحة HLS، ومسارات عامة وإدارية. تستخدم بيئة الإنتاج PostgreSQL عبر `psycopg`، بينما يسمح الإعداد الافتراضي بـSQLite لتشغيل اختبارات محلية سريعة دون خدمة خارجية.

تتضمن الواجهات العامة `GET /health` و`GET /api/channels` و`GET /api/channels/{id}` و`GET /api/channels/search?q=...` و`GET /api/categories`. تتطلب عمليات الإدارة مفتاح `X-Admin-Key` مطابقًا للمتغير `ADMIN_API_KEY`.

## فحص الصحة

تقبل خدمة الفحص قناة `verified` من نوع HLS فقط. وتتحقق من استجابة ناجحة ووجود `#EXTM3U` وأحد وسوم HLS الأساسية، مع تسجيل الحالة والوقت. لا تنفذ الخدمة أي اكتشاف لروابط بديلة أو تجاوز حماية أو DRM. القنوات التي لا تملك رابط HLS معلن تسجل `unknown` بدل التخمين.

## Flutter

يستخدم تطبيق Flutter نماذجًا مطابقة لاستجابة الـAPI، وخدمة HTTP منفصلة، ووحدة تفضيلات محلية للمفضلة، ووحدة بث HLS مستقلة عن الشاشات. شاشة البداية عربية RTL وبتصميم Dark Mode، وتضم البحث والتصنيف وشبكة القنوات. شاشة التفاصيل تعرض المشغل فقط عند وجود `stream_url` مصرح به، وإلا تعرض زر فتح المصدر الرسمي.

## قابلية التوسع

صُمم نموذج القنوات بحيث يمكن إضافة المستخدمين والمفضلة وسجل المشاهدة والإشعارات لاحقًا. في النسخة الحالية تُخزن المفضلة محليًا لتجنب فرض حسابات، ويمكن نقلها لاحقًا إلى جداول مرتبطة بالمستخدم دون تغيير عقد API العام للقنوات.
